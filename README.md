# Jagdish Sports Academy

Crimson Arena website for the taekwondo academy at 91, Rajendra Nagar, Bharatpur, Rajasthan 321001.

## Local preview

Requires Node.js. No packages or build step are needed.

```sh
npm run dev
```

Open http://127.0.0.1:8765. Run `npm run check` to check JavaScript syntax.

## Hosting

Publish the `dist` directory on a static host. `vercel.json` selects it as the Vercel output directory. Update the canonical, Open Graph and sitemap origin if moving to a different public domain.

## Enquiries

The compact form validates name and a 10-digit Indian mobile number, then opens a prepared message in WhatsApp addressed to the academy's verified listing number, +91 70142 89874. The visitor must tap Send in WhatsApp to deliver it. There is no email backend, stored enquiry database, or simulated delivery message.

## Business details and photographs

Contact details, location, rating snapshot and original academy photos were taken from the supplied Google Maps business listing. The site includes an interactive Google map, a directions link, a gallery with keyboard-accessible lightbox, and mobile navigation. Confirm current fees, timings and suitability with the academy; these are not invented on the website.

Motion respects reduced-motion preferences. Source is plain HTML, CSS, JavaScript and SVG.
