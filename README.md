# Dragon Warriors Martial Arts Academy

Crimson Arena website for Dragon Warriors Martial Arts Academy at 1759, near Kali Ki Bagichi, Kamal Colony, Tilak Nagar, Bharatpur, Rajasthan 321001.

## Local preview

Requires Node.js. No packages or build step are needed.

```sh
npm run dev
```

Open http://127.0.0.1:8765. Run `npm run check` to check JavaScript syntax.

## Hosting

Publish the `dist` directory on a static host. `vercel.json` selects it as the Vercel output directory. Update the canonical, Open Graph and sitemap origin if moving to a different public domain.

## Enquiries

The compact form validates name and a 10-digit Indian mobile number, then opens a prepared message in WhatsApp addressed to the academy's verified listing number, +91 83029 53506. The visitor must tap Send in WhatsApp to deliver it. There is no email backend, stored enquiry database, or simulated delivery message.
